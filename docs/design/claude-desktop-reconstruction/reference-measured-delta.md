# Claude Desktop 实测对照（真实截图基准）

日期：2026-11-18。证据来源：用户提供的当前 Claude Desktop 真实窗口截图四张（`reference/*.png`，2x retina）。
这是首次拿到可直接测量的真实运行态参考，此前 `reference-measurements.json` 只有静态样式声明，CDR-09 处于阻塞。

标注约定：**实测** = 从截图像素直接读出的值；**推断** = 由实测几何推导；**未验证** = 截图不含该状态。

## 侧栏导航（实测，空态截图）

顺序：`New` / `Search` / `Projects` / `Artifacts` / `Scheduled` / `Customize`

- 顶行 `New` 是带 `+` 的强调行（有独立底色），不是普通行。
- 分组标题带 `⌄` 折叠图标：`Recent`、`decipher`、`XBuild`、`Desktop`、`dsh-swift`、`EEGdata`、`UAD`。
- 列表项后带状态图标：橙色 ⚠ 表示待处理/失败。
- 底部账户行：`✳ xiatian · Gateway ⌄` + 右侧齿轮。

## 会话视图（实测，split 截图）

- 头部：标题 + `⌄`；右侧图标组顺序为 清单 / `>_` / 图片 / 地球 / 文件夹 / `…` / `X`。
- 活动行：单行灰色摘要，尾部绿色 `+212`、红色 `1 failed`，右侧 `⌄`。
- 消息动作区：`View changes` 胶囊 + 图标行（复制/重试/分享）+ 相对时间 `4 days ago`。
- 错误内联行：`⚠ Invalid request` + `View details ›`。

## 三栏视图（实测）

- 中栏为会话，右栏为 `Terminal` + `Files` 上下分割（CodeMirror 风格文件树）。
- Files 面板：`Filter, or ? to search in files` 搜索框、目录树、右侧 git 状态点。
- diff 卡：`feat/pe… working…` + 文件计数 + `+2` 增删统计。

## 错误态（实测）

圆角描边卡：`⚠ Can't reach 127.0.0.1:15721` / 副标题 / 下划线 `Details` / 胶囊按钮 `Open Setup`、`Check again` / 右上 `X`。
